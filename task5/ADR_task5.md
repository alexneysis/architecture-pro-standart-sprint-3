### <a name="_qmphm5d6rvi3"></a>**Решение**

Для онлайн-подачи кредитных заявок предлагается добавить отдельный сервис кредитных заявок. Он будет принимать заявки с сайта и интернет-банка, хранить их статус и передавать заявки в кредитный конвейер через API.

Для клиентов интернет-банка дополнительно отображаются предодобренные предложения, если по клиенту уже был рассчитан скоринг. После подачи заявки выполняется повторная проверка скоринга по упрощённой процедуре, если ситуация по клиенту изменилась.

Клиент получает SMS-уведомления о необходимости посетить отделение и об изменении статуса заявки.

### <a name="_bjrr7veeh80c"></a>**Альтернативы**

1. Реализовать онлайн-кредитование напрямую в АБС.

Плюс: АБС уже содержит клиентов, счета и часть кредитных данных.
Минусы: БД АБС уже перегружена, АБС масштабируется только вертикально. Дополнительная онлайн-нагрузка создаёт риск для основной банковской системы. Вариант не выбран.

2. Интегрировать сайт и интернет-банк напрямую с кредитным конвейером.

Плюс: меньше промежуточных компонентов.
Минусы: сайт и интернет-банк будут сильно связаны с кредитным конвейером. Также потребуется дублировать логику статусов, идентификаторов заявок и SMS-уведомлений в разных каналах. Вариант не выбран.

**Недостатки, ограничения, риски**

1. Появляется новый сервис кредитных заявок, который нужно разрабатывать, сопровождать и мониторить.

2. Кредитный конвейер остаётся основной системой обработки заявки. Если он недоступен, заявка может быть принята, но её обработка будет отложена.

3. Для новых клиентов полное оформление кредита онлайн невозможно без идентификации в отделении.

4. Требуется синхронизация статусов между сервисом кредитных заявок, кредитным конвейером и АБС.
