### <a name="_qmphm5d6rvi3"></a>**Решение**

Для MVP предлагается выделить централизованный справочник депозитных ставок. Он будет использоваться как единый источник актуальных ставок для сайта, интернет-банка, внутреннего кол-центра и партнёрского кол-центра.

Сотрудники депозитного и кредитного бэк-офиса работают со ставками через АБС. АБС остаётся системой, в которой ставки утверждаются и хранятся как банковские данные. Для снижения нагрузки на АБС актуальные ставки публикуются в отдельный справочник депозитных ставок, из которого их читают онлайн-каналы и система кол-центра.

Внутренний кол-центр получает ставки через интеграцию со справочником ставок. Это позволяет менеджерам консультировать клиентов по актуальным условиям без ручного обмена файлами.

Партнёрский кол-центр не может выполнять API-вызовы, поэтому для него формируется регулярная файловая выгрузка с актуальными ставками. Файл передаётся по защищённому каналу, например через SFTP. В файле указываются продукт, ставка, срок, валюта, дата начала действия и дата формирования выгрузки.

Такое решение позволяет убрать XLS-файлы из основного процесса, снизить нагрузку на АБС и обеспечить единый источник ставок для всех каналов.

### <a name="_bjrr7veeh80c"></a>**Альтернативы**

1. Передавать ставки во внутренний и партнёрский кол-центр вручную в XLS-файлах.

Плюс: минимальные доработки систем.
Минусы: высокий риск устаревших данных, ручной труд, ошибки при передаче файлов. Вариант не выбран, так как не решает проблему актуальности ставок.

2. Дать системе кол-центра прямой доступ к АБС.

Плюс: кол-центр получает ставки из первоисточника.
Минусы: АБС уже перегружена, а её база данных масштабируется только вертикально. Дополнительная нагрузка от кол-центра создаёт риск для основной банковской системы. Вариант не выбран.

**Недостатки, ограничения, риски**

1. Появляется новый компонент — справочник депозитных ставок, который нужно разрабатывать и сопровождать.

2. Нужно обеспечить синхронизацию данных между АБС и справочником ставок. При ошибке синхронизации каналы могут показывать устаревшие ставки.

3. Для партнёрского кол-центра данные будут передаваться файлами, поэтому ставки у партнёра могут обновляться не мгновенно.
